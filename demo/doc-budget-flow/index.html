역할별 할 일

실무부서

  • 집행 전 예산 품의서 작성 · 유형 선택
  • 온라인 결제가 필요하면 「온라인 결제 · 사용」 선택
  • 품의 금액 안에서 집행
  • 광고비: 매월 월마감 전 광고비 집행 보고서 + 결제 영수증

결재자

  • 예산 품의서: 품의 금액 · 예정 지출일 확인
  • 지출 내역의 결제방법 · 법인카드 결제분 확인
  • 광고비 보고서: 결제액 · ROAS 확인

재무회계팀

  • 결재 완료 후 카드 번호 발급 · 한도 세팅 · 안내
  • 광고비: 재무팀 광고 카드(모카드) 하위로 안내
  • 광고비 보고서 취합 → 카드 승인내역 대조 → 지출결의서 작성

양식: 예산 품의서 · 광고비 집행 보고서 (회계시스템 기안양식) · 양식 화면은 회계시스템 본문 파일 원본에 예시값만 채운 것
